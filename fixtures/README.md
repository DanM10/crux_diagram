# Conformance fixtures

Shared by every implementation of the drawing format (Dart and TypeScript).
The format is defined in the shared spec 02; these files are its executable
form. **Generated by `tool/generate_fixtures.dart` — do not edit by hand**:

```
cd dart && flutter test tool/generate_fixtures.dart
```

| Folder | A conforming implementation must |
|---|---|
| `valid/` | Accept every document (FMT-080). |
| `invalid/` | Reject every document (FMT-081). Only accept/reject is checked, never the message. Some files are not valid JSON on purpose, so read them as text and treat a parse failure as a rejection. |
| `roundtrip/` | Read, write and get the same document back, comparing numbers with a `1e-6` tolerance and ignoring key order (FMT-082). If `<name>.expected.json` exists, compare with it instead of the input. |
| `geometry/` | Match every `expected` within `1e-6` (FMT-083). |
| `drawing-geometry/` | Give `expected` from `computeGeometry(document)` within `1e-6`, measuring with `ApproximateTextMeasurer` (spec 06). |

## Geometry files

```json
{
  "function": "anchorsOf",
  "description": "...",
  "cases": [{ "name": "...", "input": { }, "expected": { } }]
}
```

`input` and `expected` are plain JSON; the shapes per function are visible in
`dart/test/conformance/geometry_cases.dart` (the Dart adapter) and in the files
themselves. A `null` expected value means "no result" (for example
`leaderLineStart` when the anchor is inside the label).

## Drawing geometry files

The exception to the Dart generator: Flutter has no `computeGeometry` (spec 06), so
these files are **generated by `js/core/scripts/generate-drawing-geometry.mjs`**, still
never edited by hand:

```
cd js/core && node scripts/generate-drawing-geometry.mjs
```

```json
{
  "description": "...",
  "measurer": "ApproximateTextMeasurer",
  "documentIsValid": true,
  "document": { },
  "expected": { "geometryVersion": 1, "canvas": { }, "shapes": [], "joints": [] }
}
```

`document` is read as plain JSON, not through `parse`. `documentIsValid` is `false`
when the document fails `validate` on purpose (a joint whose shape does not exist).
`ApproximateTextMeasurer` makes every character `0.6 × fontSize` wide (`0.65` in bold)
and the line `1.2 × fontSize` tall. A painter can also check `expected` with its own
port of `validateGeometry`.

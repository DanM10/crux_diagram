# fixtures/

Shared conformance fixtures. Read `README.md` here for the file formats.

## Rules

- **Do not edit files by hand.** They are generated by `../dart/tool/generate_fixtures.dart`:
  `cd ../dart && flutter test tool/generate_fixtures.dart`.
- To add or change a case, edit the generator, regenerate, and review the diff of the generated files.
- Expected geometry values come from the Dart code, so they are only as trustworthy as their review. For anything non-trivial, check them with an independent calculation.
- A regenerated diff that changes existing expected values means behavior changed: this is a format change, so `../spec/02-spec-formato-json.md` and every implementation must be updated too.
- Fixtures are language-neutral plain JSON. Do not add anything Dart-specific.
- `invalid/` cases must fail for the reason their name states, not by accident.
